## 작성 규칙

- **대제목** = 주제 분류 (예: 순차 회로 & 타이밍, 조합 논리, RTL 설계, 검증)
- **Q 항목** = 면접관이 물을 법한 질문 형태로 재구성
- 각 Q 항목 구성
  - `출처` : 숙제 / 수업 / 의문 + 날짜
  - `처음 이해` : 토론 전 내 생각 (틀린 부분 포함, 성장 과정 기록)
  - `핵심 정리` : 토론 결과, 정확한 내용만
  - `면접 답변` : 30초~1분 분량 구두 답변
  - `꼬리 질문` : Claude 출제 → 내 답변 → 피드백
  - `근거` : 교재 / 표준 / 데이터시트 등
- 정확성 표시
  - ✅ 표준 교재·데이터시트로 확인된 내용
  - ⚠️ 조건부 / 공정·툴마다 다름 (면접에서 단정 금지)
- **문제 해결 경험**은 STAR 형식 (Situation · Task · Action · Result)
