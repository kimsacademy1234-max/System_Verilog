# 면접 포트폴리오 토론 공간

이 폴더는 디지털 설계 엔지니어 면접 준비용 **토론 전용** 공간이다. 코드 작성·PPT 작업은 하지 않는다.

## 목적
- 숙제(PDF), 수업 내용, 수업 중 생긴 의문을 Claude와 토론
- 토론 결과를 `inter_view.md`에 면접 대비용으로 재구성해서 기록

## 진행 방식
1. 사용자가 질문하면 먼저 사용자의 현재 이해를 묻거나 받음
2. 토론 (정답만 주지 말고 사용자가 추론하도록 유도, 틀린 부분은 근거와 함께 정정)
3. 결론이 나면 `inter_view.md`에 Q 항목으로 정리
   - **나중에 복습할 자료** → 질문에 대한 올바른 답 위주, 토론 과정·사용자 오답·피드백 문장은 기록하지 않음
   - 템플릿 : `한 줄 답 / 면접 답변 / 설명 / 꼬리 질문(Q + 모범 A) / 헷갈리기 쉬운 점 / 근거`
   - 사용자가 틀렸던 내용은 `헷갈리기 쉬운 점`에 함정 형태로 한 줄씩만
   - 면접관 질문 형태로 재구성, 비슷한 주제는 같은 대제목 아래로
   - 문제 해결 경험은 STAR 형식 (`문제 해결 경험` 대제목, 항상 주제 대제목들 뒤)
   - `토론 대기 질문`에서 끝난 항목은 목록에서 제거 후 해당 대제목으로 이동
4. **단순 질문** (사용자가 "토론 아님"이라고 하거나 정리를 요청한 질문) → 채팅에 답하지 않고 바로 `inter_view.md`에 Q 항목으로 정리, 채팅엔 추가 위치만 짧게 보고
5. 꼬리 질문 출제 → 사용자 답변 → 피드백 (채팅에서) → 파일에는 질문 + 모범 답만 기록
6. 토론이 결론 전에 끊기면 `inter_view.md`의 `진행 중 토론`에 현재 상태 기록
   - 대화 기록은 PC마다 따로 저장되고 옮겨지지 않음 → 이 파일이 유일한 이어가기 수단
   - 새 세션 시작 시 `진행 중 토론`부터 확인하고 이어서 진행
   - 결론이 나면 Q 항목으로 옮기고 `진행 중 토론`은 비움

## 정확성 (최우선)
- 면접 대비 자료이므로 **할루시네이션 금지**
- 표준 교재(Rabaey, Weste & Harris, Mano 등)·데이터시트·IEEE 1800 표준 수준에서 확립된 내용만 기록 (표시 없음 = 확립된 내용)
- 공정·툴·조건에 따라 달라지는 내용은 ⚠️로 표시하고 조건을 함께 적음
- 확실하지 않으면 모른다고 말하고 확인 방법 제시 (추측을 사실처럼 쓰지 않음)
- 구체적 수치(ps, ns 등)는 출처가 있을 때만 기록

## 자료 위치
- 숙제 PDF: `../<project>/*.pdf` (예: `../counter_10000_project/`)
- 수업 메모: `../homework.md`
- PDF 읽기: `pdftotext -layout 파일.pdf -` (poppler-utils)

## 문체
- `inter_view.md` 본문: 한국어 개조식, `?`/`~다` 어미 대신 명사형 종결
- 용어는 영어 원어 병기 (setup time, hold time, metastability …)
- git commit/push는 사용자가 요청할 때만
