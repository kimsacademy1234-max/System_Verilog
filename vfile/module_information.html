3. 모듈 상세

half_adder

조합

half_adder.v · 1-bit 반가산기 · o_sum = i_a ^ i_b, o_cout = i_a & i_b

방향이름폭설명
INi_a1피연산자 A
INi_b1피연산자 B
OUTo_sum1합
OUTo_cout1캐리 출력
인스턴스 예시
half_adder U_HALF_ADDER (
    .i_a    (),
    .i_b    (),
    .o_sum  (),
    .o_cout ()
);

full_adder

조합

full_adder.v · 1-bit 전가산기 · {o_cout, o_sum} = i_a + i_b + i_cin · 하위 모듈: half_adder ×2

방향이름폭설명
INi_a1피연산자 A
INi_b1피연산자 B
INi_cin1캐리 입력
OUTo_sum1합
OUTo_cout1캐리 출력
인스턴스 예시
full_adder U_FULL_ADDER (
    .i_a    (),
    .i_b    (),
    .i_cin  (),
    .o_sum  (),
    .o_cout ()
);

full_adder_4bit

조합

full_adder_4bit.v · 4-bit 리플 캐리 가산기 · {o_cout, o_sum} = i_a + i_b + i_cin · 하위 모듈: full_adder ×4

방향이름폭설명
INi_a[3:0]피연산자 A
INi_b[3:0]피연산자 B
INi_cin1캐리 입력 (안 쓰면 1'b0)
OUTo_sum[3:0]합
OUTo_cout1캐리 출력
인스턴스 예시
full_adder_4bit U_FULL_ADDER_4BIT (
    .i_a    (),
    .i_b    (),
    .i_cin  (),
    .o_sum  (),
    .o_cout ()
);

full_adder_8bit

조합

full_adder_8bit.v · 8-bit 리플 캐리 가산기 · {o_cout, o_sum} = i_a + i_b + i_cin · 하위 모듈: full_adder_4bit ×2

방향이름폭설명
INi_a[7:0]피연산자 A
INi_b[7:0]피연산자 B
INi_cin1캐리 입력 (안 쓰면 1'b0)
OUTo_sum[7:0]합
OUTo_cout1캐리 출력

full_adder_8bit U_FULL_ADDER_8BIT (
    .i_a    (),
    .i_b    (),

digit_splitter

조합

digit_splitter.v · 2진수 → 10진 자릿수 4개 (BCD) · o_digit_N = (i_data / N) % 10

방향이름폭설명
PARAMWIDTH기본 9입력 비트 폭 (9 → 0~511)
INi_data[WIDTH-1:0]변환할 2진수
OUTo_digit_1[3:0]1의 자리
OUTo_digit_10[3:0]10의 자리
OUTo_digit_100[3:0]100의 자리
OUTo_digit_1000[3:0]1000의 자리
인스턴스 예시
digit_splitter #(
    .WIDTH (9)
) U_DIGIT_SPLITTER (
    .i_data       (),
    .o_digit_1    (),
    .o_digit_10   (),
    .o_digit_100  (),
    .o_digit_1000 ()
);

fnd_decoder

조합

fnd_decoder.v · hex(0~F) → 7-segment 폰트 · active-low, {dp,g,f,e,d,c,b,a}, 0 → 8'hC0

방향이름폭설명
INi_hex[3:0]표시할 값 0~F
OUTo_fnd_data[7:0]세그먼트 패턴 (0 = 켜짐)
인스턴스 예시
fnd_decoder U_FND_DECODER (
    .i_hex      (),
    .o_fnd_data ()
);

decoder_2x4

조합

decoder_2x4.v · 2-to-4 디코더 (active-low) · 00→1110, 01→1101, 10→1011, 11→0111

방향이름폭설명
INi_sel[1:0]선택값
OUTo_dec_n[3:0]active-low one-hot (FND 자리 선택용)
인스턴스 예시
decoder_2x4 U_DECODER_2X4 (
    .i_sel   (),
    .o_dec_n ()
);

mux_4x1

조합

mux_4x1.v · 4-to-1 멀티플렉서 · o_data = i_d[i_sel]

방향이름폭설명
PARAMWIDTH기본 4데이터 비트 폭
INi_sel[1:0]선택값
INi_d0[WIDTH-1:0]i_sel = 0 일 때 출력
INi_d1[WIDTH-1:0]i_sel = 1 일 때 출력
INi_d2[WIDTH-1:0]i_sel = 2 일 때 출력
INi_d3[WIDTH-1:0]i_sel = 3 일 때 출력
OUTo_data[WIDTH-1:0]선택된 데이터
인스턴스 예시
mux_4x1 #(
    .WIDTH (4)
) U_MUX_4X1 (
    .i_sel  (),
    .i_d0   (),
    .i_d1   (),
    .i_d2   (),
    .i_d3   (),
    .o_data ()
);

carry_display

순차

carry_display.v · 합 / 캐리 2자리 FND 스캔 · 클럭마다 digit0(합) ↔ digit1(캐리) 교대

방향이름폭설명
INi_clk1클럭 (posedge)
INi_rst_n1비동기 리셋 (active-low)
INi_cout1표시할 캐리
INi_fnd_data[7:0]digit0 폰트 (fnd_decoder 출력)
OUTo_fnd_data[7:0]세그먼트 출력 (active-low)
OUTo_fnd_com[3:0]자리 선택 (active-low)
인스턴스 예시
carry_display U_CARRY_DISPLAY (
    .i_clk      (),
    .i_rst_n    (),
    .i_cout     (),
    .i_fnd_data (),
    .o_fnd_data (),
    .o_fnd_com  ()
);
