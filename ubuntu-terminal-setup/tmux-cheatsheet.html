tmux 사용법

WSL + tmux 환경 기준 · 내 설정 표시는 ~/.tmux.conf / ~/.bashrc에 직접 추가한 기능

대부분의 단축키는 prefix인 Ctrl+b를 누르고 손을 뗀 다음 다음 키를 누릅니다. 표에서 Ctrl+b→%는 이 순서를 뜻합니다.

창 분할

Ctrl+b→| 내 설정좌우 분할
Ctrl+b→- 내 설정상하 분할
Ctrl+b→%좌우 분할 (기본 키)
Ctrl+b→"상하 분할 (기본 키)
v 내 설정셸에서 입력: 좌우 분할
h 내 설정셸에서 입력: 상하 분할
t4 내 설정새 세션을 2×2로 4분할해서 열기 (tmux 밖에서)

분할한 새 창은 현재 폴더에서 시작합니다. v/h는 tmux 안에서만 동작합니다.

창 이동

Ctrl+w→w 내 설정다음 창으로 순서대로 이동 (vim 창 ↔ tmux 창)
Ctrl+h/j/k/l 내 설정왼쪽 / 아래 / 위 / 오른쪽 창으로 이동
Ctrl+w→h/j/k/l 내 설정방향으로 이동
Ctrl+b→방향키방향으로 이동
Ctrl+b→o다음 창으로 순환
Ctrl+b→q창 번호 표시 (보이는 동안 번호를 누르면 이동)
마우스 클릭클릭한 창으로 이동 내 설정

vim 안에서는 일반 모드에서만 이동됩니다. 입력 모드면 Esc 먼저.

창 조작

Ctrl+b→z현재 창 최대화 / 복귀
Ctrl+b→x현재 창 닫기 (셸에서 exit도 가능)
Ctrl+b→Ctrl+방향키창 크기 조절 (마우스로 경계선 드래그도 가능)
Ctrl+b→Space레이아웃 순환 (균등 배치, 세로 배치 등)
Ctrl+b→{ / }창 위치 서로 바꾸기
Ctrl+b→Ctrl+l 내 설정셸 화면 지우기 (clear와 같음)

세션 관리

tmux ls세션 목록 (번호, 생성 시각, 접속 중 여부)
Ctrl+b→s세션 트리 + 미리보기. Enter 이동, x 종료
Ctrl+b→w세션과 창 전체를 트리로 보기
Ctrl+b→d세션에서 나가기 (세션은 계속 실행됨)
tmux attach마지막 세션에 다시 접속
tmux attach -t 2121번 세션에 접속
tmux kill-session -t 2121번 세션 종료
tmux kill-server모든 세션 종료 (저장 안 한 vim 내용 사라짐)

t4는 실행할 때마다 새 세션을 만들고, 창을 닫아도 세션은 남습니다. 가끔 Ctrl+b→s로 정리하세요.

지나간 출력 보기 (스크롤)

마우스 휠 내 설정바로 위로 스크롤
Ctrl+b→[스크롤 모드 시작
↑↓ PgUp PgDn스크롤 모드에서 이동
/ 또는 ?스크롤 모드에서 아래 / 위로 검색
q스크롤 모드 끝내기

세션 내용 확인 · 기록

tmux capture-pane -p -t 2121번 세션 화면을 들어가지 않고 텍스트로 출력
tmux pipe-pane -o 'cat >> ~/tmux-#S-#P.log'현재 창 출력을 파일로 계속 저장. 한 번 더 실행하면 중지

tmux는 세션 기록을 따로 저장하지 않습니다. 파일로 남기려면 pipe-pane을 쓰세요. 로그는 ~/tmux-세션명-창번호.log에 쌓입니다.

자주 쓰는 흐름

t4                      # 4분할 세션 열기
vim StopWatch.v         # 왼쪽 위에서 코드 편집
Ctrl+w w                # 옆 창(터미널)으로 이동해서 시뮬레이션 실행
Ctrl+b z                # 보고 싶은 창만 잠깐 크게 보기, 한 번 더 누르면 복귀
Ctrl+b d                # 작업 두고 나가기 → 나중에 tmux attach 로 이어서

설정 파일을 바꾼 뒤에는 tmux source-file ~/.tmux.conf, 셸 alias를 바꾼 뒤에는 이미 열린 창에서 source ~/.bashrc를 실행해야 적용됩니다.
